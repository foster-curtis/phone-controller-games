# UI reference screens

PNG renders of the UI mockups. They're for reference only: the screens are built in code (SPEC §2.6).

- **`phone/`:** 10 phone screens at 2x the 844 x 390 reference viewport, landscape. The phone frame is included.
- **`tv/`:** 6 TV screens at 1920 x 1080. The faint dashed rectangle is the 96 px TV-safe margin, not part of the UI.

Prices, cell costs, names and numbers are placeholders. Foster is cobalt in every example.
